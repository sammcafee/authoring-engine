# Measure Twice Is a Lie

Everyone says measure twice, cut once. It's on a tea towel in my shop,
actually, a gift from my sister who thinks this is very funny given how many
boards I've ruined.

Measuring twice only helps if the second measurement is independent of the
first. Most of the time it isn't. I measure, I write the number down, and
then I "double check" by looking at the same tape at the same mark and
confirming that yes, it still says what I wrote. That's not a second
measurement. That's reading my own handwriting back to myself and calling it
verification.

The boards I've actually ruined were ruined by a single wrong number I
confirmed twice, both times against itself. The saves came from something
different: measuring once, then measuring again from a different reference
point entirely, so an error in the first pass had no way to survive into the
second.

The tea towel should say measure from two different starting points, cut
once. It wouldn't fit as well on a tea towel. I get why nobody writes it that
way. I still think about it every time I pick up the tape.
